# 威科夫方法学习讲义（中文）

一份中文的威科夫方法（Wyckoff Method）学习讲义，面向加密市场的交易者。**学习用，不构成任何买卖建议。**

## 内容

- **威科夫其人与“综合人”（Composite Man）** —— 方法的来源和核心思考工具
- **三大定律** —— 供求、因果、努力与结果
- **吸筹结构（Accumulation）** —— 阶段 A–E：PS / SC / AR / ST / Spring / Test / SOS / LPS / JAC·BU，逐个讲样子、机制、怎么确认
- **派发结构（Distribution）** —— PSY / BC / AR / ST / UTAD / SOW / LPSY，与吸筹一一对应
- **再吸筹与再派发** —— 两者在形成时几乎一样，附辅助判断
- **量价分析（VSA）基础** —— 止跌量、无供给、无需求、上冲、努力无结果
- **威科夫用在加密市场** —— 24/7 没有收盘、周末低量、永续 OI 与强平、资金费率、现货 CVD vs 永续 CVD
- **卖出高潮（SC）判定清单** —— 7 条可逐条打勾的证据，附每条为什么看它
- **案例：BTC 2026-11-15 低点 62,006** —— 逐条对照清单、机制解读、与 2020-03-13 / 2024-08-05 / 2025-04-07 的历史对照，结论是“候选 SC”而非已确认的 SC
- **常见错误与局限** —— 事后贴标签、阶段只有事后才清楚、多重检验制造假信号
- **延伸阅读** —— Wyckoff 原始课程、Pruden、Weis、Villahermosa（书名已逐一核对）
